# Glossário do Cidadão

Tradução de termos da administração pública para o texto exibido no portal. Usado pelo agente `editor-cidadao`. A coluna "Evitar" lista formulações enganosas. Valores e limites legais **não** ficam aqui: vêm de `seed_constantes_fiscais.csv`.

| Termo técnico | Texto ao cidadão | Evitar |
|---|---|---|
| Empenho | Valor reservado para uma despesa | "Gasto" |
| Liquidação | Serviço ou produto entregue e conferido | |
| Pagamento | Valor efetivamente pago | |
| Dotação orçamentária | Verba prevista para uma finalidade neste ano | "Dinheiro disponível" |
| Dotação atualizada | Verba prevista, já com os ajustes feitos no ano | |
| Restos a pagar | Contas de anos anteriores que ainda estão sendo pagas | "Dívida" sem contexto |
| Restos a pagar processados | Já entregues e conferidos: o fornecedor cumpriu a sua parte e falta o pagamento | "Direito adquirido do credor" |
| Restos a pagar não processados | Ainda em andamento: depende de conferência antes do pagamento | "Pendente de liquidação" |
| LOA (Lei Orçamentária Anual) | Lei que diz quanto a prefeitura pode gastar e quanto espera arrecadar no ano | "Orçamento fixo" |
| FPM | Repasse do governo federal aos municípios | |
| ICMS (cota-parte) | Parte do imposto estadual sobre vendas que o estado repassa ao município | |
| Receita extra-orçamentária | Dinheiro que passa pelo caixa da prefeitura, mas não faz parte do orçamento (retenções e caixas) | "Receita própria" |
| Emenda Pix | Transferência especial de deputado ou senador direto ao município, sem destino fixado | |
| Empenho | Valor reservado para um gasto | "Gasto" sem qualificação |
| Receita Corrente Líquida (RCL) | Receita do município nos últimos 12 meses, usada como base para limites da lei | |
| Limite prudencial | Nível de alerta em que a lei já impede novos aumentos de despesa com pessoal | |
| Dispensa de licitação | Compra feita sem concorrência, nos casos que a lei permite | "Compra irregular" |
| Fracionamento | Dividir uma compra em partes para ficar abaixo do limite que exige licitação | "Fraude" |
| Potencial alerta de fracionamento | Compras parecidas e frequentes que merecem conferência no processo | "Irregularidade" |
| Aditivo contratual | Mudança em um contrato já assinado (prazo ou valor) | |
| RPPS / CAPREM | Fundo de aposentadoria dos servidores do município | |
| Dívida ativa | Valores que pessoas e empresas devem ao município | |
| Transferência constitucional | Parte de impostos federais e estaduais que a lei manda repassar ao município | "Ajuda" |
| Emenda parlamentar | Verba indicada por deputado ou senador para uma obra ou serviço local | |
| Parecer / acórdão | Decisão ou opinião formal de órgão de controle (ex.: Tribunal de Contas) | |
| Sem registro de estoque informado | "Não aparece na lista de estoque": ausência na última lista oficial, não prova de falta | "Esgotado", "zerado" |
| Combinação em dose fixa | Remédio misturado com outro no mesmo comprimido | |
| Unidade ativa (farmácia SUS) | Posto ou unidade de saúde que enviou a lista de estoque recentemente | |
| Posição de estoque | A lista de estoque de um dia específico | |
| SUS (Sistema Único de Saúde) | A rede pública e gratuita de saúde do país: postos, hospitais e farmácias mantidos com dinheiro público | |
| Produção do SUS | Atendimentos e internações que as unidades registraram no SUS | |
| Por mil moradores | Para cada 1.000 pessoas que moram no município. Serve para comparar com anos anteriores sem depender do tamanho da cidade | |
| Leito do SUS | Cama de hospital ou posto que atende pelo SUS, segundo o cadastro de estabelecimentos de saúde (CNES) | |
| Internação | Entrada de uma pessoa no hospital para ficar mais de um dia, paga pelo SUS (a autorização se chama AIH) | |
| Atendimentos e internações feitos na cidade | O que o SUS registrou e pagou em estabelecimentos da cidade. Quem mora aqui e se trata em outra cidade não entra na conta daqui, e cidades que atendem gente de fora aparecem com números maiores | |
| Para fiscalizar | Parte da página para quem quer conferir contrato por contrato, fornecedor por fornecedor e emenda por emenda; vem recolhida, com um resumo à vista | |
| Lote (de remédio) | Remessa de um mesmo remédio com a mesma data de validade | "Lote irregular", "lote vencido" sem dizer que consta com saldo na lista |
| Remédio só com lote vencido | "Na lista de estoque, todos os lotes dele estão com a validade vencida" | "Remédio vencido", "sem estoque", "irregular" |
| IDEB | Nota de 0 a 10 que o governo federal dá às escolas, combinando o que os alunos aprendem nas provas e quantos são aprovados. É medida de dois em dois anos | "Ciclo oficial", "troféu cívico" |
| Saeb | Prova nacional que mede o que os alunos aprendem em português e matemática. Entra no cálculo do IDEB | |
| FUNDEB | Fundo federal que ajuda a pagar a educação básica: reúne impostos e devolve aos municípios conforme o número de alunos | "Verba da educação" sem dizer a origem |
| PNAE | Programa federal que manda dinheiro para a merenda escolar | |
| PNATE | Programa federal que manda dinheiro para o transporte escolar | |
| Fundo Municipal de Educação | Caixa específico da educação no município, que recebe os repasses federais e estaduais e parte da Prefeitura | "Fundo de Educação" |
| Empenho líquido | Valor reservado depois de descontar os cancelamentos feitos no ano | "Empenhado bruto" |
| SIOPE | Sistema do governo federal em que a Prefeitura informa o que aplica em educação. O portal mostra o número como o governo federal o publicou, sem recalcular | "Conferido pelo portal", "auditado" |
| FNDE | Órgão do governo federal que cuida do dinheiro da educação e publica os dados do SIOPE. Na tela, preferir "governo federal" | |
| EJA (Educação de Jovens e Adultos) | Escola para quem não estudou na idade certa e quer concluir o ensino fundamental ou médio | |
| MDE (manutenção e desenvolvimento do ensino) | Gastos da Prefeitura com escolas, professores, material e transporte escolar. A lei manda aplicar um mínimo da receita de impostos nisso | "Gasto com educação" sem dizer que é o mínimo exigido |
| Valor indicado (emenda) | Quanto o deputado indicou para a cidade. Não é o que já foi pago | "Valor recebido", "valor repassado" |
| Repasse direto à Prefeitura (transferência especial) | O Estado envia o dinheiro direto ao caixa da Prefeitura | "Emenda Pix" sem explicar |
| Finalidade definida | O Estado repassa à Prefeitura para um uso combinado de antemão | |
| Fundo a fundo | O dinheiro vai do fundo do Estado para o fundo do município (saúde, assistência) | |
| Cadastro da Prefeitura | A lista de emendas que a própria Prefeitura registra no seu sistema. É diferente da lista do Estado e pode ter datas diferentes. Não constar nela não significa que o dinheiro não chegou | "Omissão", "não declarou" |
| Posição do relatório (execução do Estado) | Mês e ano a que o relatório do Estado se refere. O que aconteceu depois dessa data não aparece | "Estado não pagou" a partir de valor zerado |
| O Estado gasta direto (execução direta) | O próprio Estado faz a obra ou a compra; o dinheiro não passa pela Prefeitura | "Executa" sem explicar |
| Organização da sociedade civil | Entidade privada sem fins lucrativos que recebe o dinheiro da emenda, não a Prefeitura | "OSC" sem explicar |
| Outras transferências dos Estados | Linha da receita da Prefeitura que reúne dinheiro enviado pelo Estado fora das cotas fixas. Inclui emendas, mas também outras transferências, então não prova sozinha que uma emenda chegou | "Receita da emenda" |
| Pago pelo Estado (emenda) | O que o Estado informa já ter pago no relatório de execução, até o mês indicado. É diferente do valor indicado e do que a Prefeitura registrou | "Repassado", "recebido" |
| Ainda não aparece na receita | O Estado informa ter pago mais do que a Prefeitura registrou em receita. É diferença calculada pelo portal, e os dois sistemas podem ter datas de corte diferentes | "Omissão", "desvio", "irregular" |

## Como acrescentar um termo
1. Definir o texto ao cidadão em até uma frase, sem sigla não explicada.
2. Listar a formulação enganosa a evitar.
3. Se o termo envolve limite legal, referenciar a chave em `seed_constantes_fiscais.csv`; não copiar o valor.
